## About this site

A hand-built static site served by GitHub Pages, with no build step and no frameworks.

| Path | What it is |
|---|---|
| `index.html` | Portfolio home page |
| `Core-CSE-Conference.html` | Searchable list of 891 ranked computer-science conferences |
| `assets/css/site.css` | Design system: theme tokens, light/dark themes, layout, animations |
| `assets/js/site.js` | Interactions: constellation canvas, scroll reveal, counters, tabs, filters, theme toggle |
| `assets/img/` | Portrait, mentor photos, project previews (animated WebP with GIF fallback). Icons are an inlined SVG sprite (Bootstrap Icons subset) at the top of each page |
| `assets/img/icons/`, `favicon.ico`, `site.webmanifest` | Favicons and app icons |
| `assets/img/og/` | 1200×630 social share cards (LinkedIn, X, WhatsApp previews) |
| `404.html` | Custom not-found page (served automatically by GitHub Pages) |
| `robots.txt`, `sitemap.xml` | Crawler directives and sitemap |

To preview it locally, run:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
